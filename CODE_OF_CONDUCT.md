# Code of Conduct

Wishlist is a small self-hosted project for people who care about privacy, local ownership, and simple software.

Everyone participating in this project is expected to be respectful, constructive, and patient.

## Expected Behavior

- Be kind and assume good intent.
- Keep feedback focused on the project, not the person.
- Explain problems clearly and help others reproduce them.
- Respect privacy. Do not post private wishlist data, logs with secrets, backups, passwords, tokens, or personal information.
- Use private reporting for security issues. See `SECURITY.md`.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Publishing private information without permission.
- Repeated off-topic or disruptive comments.
- Publicly disclosing unpatched security vulnerabilities.

## Enforcement

The maintainer may remove comments, close issues, block users, or restrict participation when behavior harms the project or its community.

If you see a problem, contact the repository owner privately.
